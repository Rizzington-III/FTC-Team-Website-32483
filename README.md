> WEBSITE FEATURES:
> > - 360 ROBOT VIEWER: Under resources, robot page, in menu bar
> > - TEAM GALLERY WITH CAPTIONS: Team Gallery Page in menu bar
> > - ARTICLE HUB: Currently there are no articles to read as they are in the process of being written
> > - MEET THE TEAM: Meet the Team page, in menu bar
> > - OUR MISSION STATEMENT: At story of our journey, as well as an interactive image carousel. Under resources, Mission Statement, in menu bar

> HOW IT WORKS:
> > - The dynamic background that makes this site unique was made using javascript and css stylings where the background used css movements to slowly move certain aspects of the background such as rings and hexagons in a driftwave motion that looped continuously and drifted to random points.
> > - The 3D viewer was a time-tedious process that was created by taking several photos (72 to be exact), and organizing them together into folders that represented the angle they were taken at. Then through javascript code I was able to connect each labeled image to each other and coded it so that when the viewer drags the viewer the screen would pivot to the image that shows the robot at that particular position.
